# Resource Index

The HTML version of this page is an interactive browser. The same resource data is available as Markdown:

- [Descriptions](../../.agents/descriptions/_overview.md): parameter ids, types, and flags of objects, tags, materials, shaders, and nodes, one file per `.res` file.
- [Description data types](../../.agents/descriptiondatatypes/_overview.md): the parameter types used in description resources.
- [Node spaces](../../.agents/nodespaces/_overview.md): node templates and ports of the material and scene node spaces.
