# TAB <a id="tab"></a>

|   |   |
|---|---|
| *TAB_TABS* | Normal tabs. |
| *TAB_NOSELECT* | No tabs. |
| *TAB_CYCLE* | Popup buttons instead of tabs. |
| *TAB_RADIO* | Radio buttons instead of tabs. |
| *TAB_VLTABS* | Vertical tabs, left-sided. |
| *TAB_VRTABS* | Vertical tabs, right-sided. |
