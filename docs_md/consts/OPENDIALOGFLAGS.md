# OPENDIALOGFLAGS <a id="opendialogflags"></a>

| Symbol ID | Description |
|---|---|
| NONE |  |
| IGNORELAYOUT | Set to ignore to load layout information from the layout file. |
| CLIENTCOORDINATES | Open the window position and size in window client coordinates, this means the given position and size will be adjusted with the window borders. |
| ALIGNTOPRIGHTATMOUSE | Aligns the manager at the top/right position of the current mouse position. |
