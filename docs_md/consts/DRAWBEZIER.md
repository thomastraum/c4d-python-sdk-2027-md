# DRAWBEZIER <a id="drawbezier"></a>

|   |   |
|---|---|
| *DRAWBEZIER_BX* | The X coordinate of the control point for the starting point. |
| *DRAWBEZIER_BY* | The Y coordinate of the control point for the starting point. |
| *DRAWBEZIER_CX* | The X coordinate of the control point for the ending point. |
| *DRAWBEZIER_CY* | The Y coordinate of the control point for the ending point. |
| *DRAWBEZIER_DX* | The X coordinate of the ending point. |
| *DRAWBEZIER_DY* | The Y coordinate of the ending point. |
