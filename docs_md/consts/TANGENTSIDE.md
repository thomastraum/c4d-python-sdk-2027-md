# TANGENTSIDE <a id="tangentside"></a>

|   |   |
|---|---|
| *TANGENTSIDE_NONE* | No tangent handles being modified. |
| *TANGENTSIDE_LEFT* | Modify the left tangent handle. |
| *TANGENTSIDE_RIGHT* | Modify the right tangent handle. |
