# TEX <a id="tex"></a>

|   |   |
|---|---|
| *TEX_TILE* | Texture tile enabled. |
| *TEX_MIRROR* | Texture mirroring enabled. |
| *TEX_ALPHA* | Texture uses alpha channel (for use within channel shaders). |
| *TEX_BUMP* | Bump calculation. |
