# GE_CM_FONTSORT <a id="ge-cm-fontsort"></a>

|   |   |
|---|---|
| *GE_CM_FONTSORT_FLAT* | One [`BaseContainer`](../modules/c4d/BaseContainer/index.md#c4d.BaseContainer) per font, no order guaranteed. |
| *GE_CM_FONTSORT_HIERARCHICAL* | For each font family a [`BaseContainer`](../modules/c4d/BaseContainer/index.md#c4d.BaseContainer) is stored and will hold a description for each font of the family (one container per font). The font families are sorted alphabetically. |
