# TOOLDRAW <a id="tooldraw"></a>

|   |   |
|---|---|
| *TOOLDRAW_NONE* | None. |
| *TOOLDRAW_HANDLES* | The active objects handles will be drawn. |
| *TOOLDRAW_AXIS* | The active objects axes will be drawn. |
| *TOOLDRAW_HIGHLIGHTS* | The highlights will be drawn. |
