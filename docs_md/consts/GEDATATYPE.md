# GEDATATYPE <a id="gedatatype"></a>

|   |   |
|---|---|
| *DA_NIL* | No value. |
| *DA_VOID* | PyCObject |
| *DA_LONG* | Integer. |
| *DA_REAL* | Float. |
| *DA_TIME* | [`BaseTime`](../modules/c4d/BaseTime/index.md#c4d.BaseTime). |
| *DA_VECTOR* | [`Vector`](../modules/c4d/Vector/index.md#c4d.Vector). |
| *DA_MATRIX* | [`Matrix`](../modules/c4d/Matrix/index.md#c4d.Matrix). |
| *DA_LLONG* | Integer. |
| *DA_STRING* | String. |
| *DA_FILENAME* | String. |
| *DA_CONTAINER* | [`BaseContainer`](../modules/c4d/BaseContainer/index.md#c4d.BaseContainer). |
| *DA_ALIASLINK* | [`BaseList2D`](../modules/c4d/C4DAtom/GeListNode/BaseList2D/index.md#c4d.BaseList2D). |
| *DA_MARKER* | Not used. |
| *DA_MISSINGPLUG* | Denotes a missing datatype plugin. |
| *DA_UUID* | *New in version R17.048:* [UUID](https://docs.python.org/3.9/library/uuid.html#uuid.UUID). |
| *DA_TRISTATE* | *New in version R20:* No single value. |
| *DA_CUSTOMDATATYPE* | Datatypes higher than this value are custom. |
