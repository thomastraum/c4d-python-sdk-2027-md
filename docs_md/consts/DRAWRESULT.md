# DRAWRESULT <a id="drawresult"></a>

| Symbol ID | Description |
|---|---|
| DRAWRESULT_FAILURE | There was an error while drawing. |
| DRAWRESULT_OK | Something was drawn. |
| DRAWRESULT_SKIP | There was nothing to draw in the pass. |
