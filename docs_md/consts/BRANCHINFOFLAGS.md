# BRANCHINFOFLAGS <a id="branchinfoflags"></a>

|   |   |
|---|---|
| *BRANCHINFOFLAGS_NONE* | None. |
| *BRANCHINFOFLAGS_ANIMATE* | Animate the nodes in the branch. |
| *BRANCHINFOFLAGS_HIDEINTIMELINE* | If set, the branch does not show up in the timeline. |
