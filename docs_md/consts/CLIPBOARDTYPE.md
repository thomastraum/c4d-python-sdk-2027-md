# CLIPBOARDTYPE <a id="clipboardtype"></a>

|   |   |
|---|---|
| *CLIPBOARDTYPE_EMPTY* | Clipboard is empty. |
| *CLIPBOARDTYPE_STRING* | Clipboard contains a string. |
| *CLIPBOARDTYPE_BITMAP* | Clipboard contains a bitmap. |
