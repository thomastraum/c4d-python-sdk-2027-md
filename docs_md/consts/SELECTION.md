# SELECTION <a id="selection"></a>

|   |   |
|---|---|
| *SELECTION_NEW* | Starts a new selection. |
| *SELECTION_ADD* | Adds to the current selection |
| *SELECTION_SUB* | Subtracts from the current selection. |
