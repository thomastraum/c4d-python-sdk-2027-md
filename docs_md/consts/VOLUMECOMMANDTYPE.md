# VOLUMECOMMANDTYPE <a id="volumecommandtype"></a>

|   |   |
|---|---|
| *VOLUMECOMMANDTYPE_VOLUMETOMESH* | Converts a [`VolumeObject`](../modules/c4d.modules/volume/VolumeObject/index.md#c4d.modules.volume.VolumeObject) into a [`PolygonObject`](../modules/c4d/C4DAtom/GeListNode/BaseList2D/BaseObject/PointObject/PolygonObject/index.md#c4d.PolygonObject). |
| *VOLUMECOMMANDTYPE_MESHTOVOLUME* | Converts a PolygonObject into a SDF [`VolumeObject`](../modules/c4d.modules/volume/VolumeObject/index.md#c4d.modules.volume.VolumeObject). |
| *VOLUMECOMMANDTYPE_VOLUMEBOOLE* | Boolean operation on SDF volume objects. |
| *VOLUMECOMMANDTYPE_PARTICLESTOVOLUME* | Converts particle objects and TP groups to a SDF [`VolumeObject`](../modules/c4d.modules/volume/VolumeObject/index.md#c4d.modules.volume.VolumeObject). |
| *VOLUMECOMMANDTYPE_SPLINETOVOLUME* | Converts a [`SplineObject`](../modules/c4d/C4DAtom/GeListNode/BaseList2D/BaseObject/PointObject/SplineObject/index.md#c4d.SplineObject) to a SDF [`VolumeObject`](../modules/c4d.modules/volume/VolumeObject/index.md#c4d.modules.volume.VolumeObject). |
| *VOLUMECOMMANDTYPE_FILTER* | Filters a float grid [`VolumeObject`](../modules/c4d.modules/volume/VolumeObject/index.md#c4d.modules.volume.VolumeObject). |
| *VOLUMECOMMANDTYPE_SDFFILTER* | Filters a float grid SDF [`VolumeObject`](../modules/c4d.modules/volume/VolumeObject/index.md#c4d.modules.volume.VolumeObject). |
| *VOLUMECOMMANDTYPE_SDFTOFOG* | Converts a SDF Volume to a fog [`VolumeObject`](../modules/c4d.modules/volume/VolumeObject/index.md#c4d.modules.volume.VolumeObject). |
| *VOLUMECOMMANDTYPE_FOGTOSDF* | Converts a fog Volume to a SDF [`VolumeObject`](../modules/c4d.modules/volume/VolumeObject/index.md#c4d.modules.volume.VolumeObject). |
| *VOLUMECOMMANDTYPE_RESAMPLE* | Resamples a [`VolumeObject`](../modules/c4d.modules/volume/VolumeObject/index.md#c4d.modules.volume.VolumeObject) to a new grid size. |
| *VOLUMECOMMANDTYPE_MIX* | Mix operation on several fog [`VolumeObject`](../modules/c4d.modules/volume/VolumeObject/index.md#c4d.modules.volume.VolumeObject). |
| *VOLUMECOMMANDTYPE_FIELDTOVOLUME* | Converts a field to a fog [`VolumeObject`](../modules/c4d.modules/volume/VolumeObject/index.md#c4d.modules.volume.VolumeObject). |
| *VOLUMECOMMANDTYPE_CREATESPHEREVOLUME* | Creates a sphere [`VolumeObject`](../modules/c4d.modules/volume/VolumeObject/index.md#c4d.modules.volume.VolumeObject). |
| *VOLUMECOMMANDTYPE_CREATEPLATONICVOLUME* | Creates a platonic [`VolumeObject`](../modules/c4d.modules/volume/VolumeObject/index.md#c4d.modules.volume.VolumeObject). |
