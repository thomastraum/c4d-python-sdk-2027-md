# Cinema 4D Python SDK 2027.0.0: Markdown Documentation Index

Markdown conversion of the official HTML documentation. Every page mirrors the path of the online page under https://developers.maxon.net/docs/py/2027_0_0/ with `.html` replaced by `.md`.

- Find a symbol: search [symbols.tsv](symbols.tsv) for its name, for example `c4d.documents.BaseDocument.InsertObject`, `c4d.COPYFLAGS_NO_HIERARCHY`, `Osphere`, or `PRIM_SPHERE_RAD`. The `path` column is the file and anchor relative to the SDK root.
- Start page of the documentation: [index.md](index.md)

- [Manuals](index/manuals.md): Conceptual guides: quickstart, scene structure, plugins, resources. (24 pages)
- [Cinema API Reference](index/cinema_api.md): Modules, classes, and functions of `c4d` and `mxutils`. (246 pages)
- [Maxon API Reference](index/maxon_api.md): Frameworks, interfaces, data types, and enums of the `maxon` package. (1159 pages)
- [Type Indexes](index/types.md): Object, tag, shader, material, track, and field type ids. (13 pages)
- [Constants](index/consts.md): Enumerations and symbol groups such as `COPYFLAGS` or `DIRTYFLAGS`. (322 pages)
- [Examples](index/examples.md): Annotated example scripts and plugins of the SDK. (198 pages)
- [Other Indexes](index/indexes.md): What's new, example index, type index, resource index. (4 pages)
