# Manuals

> Conceptual guides: quickstart, scene structure, plugins, resources.

- [Manuals](../manuals/index.md): Browse guides for Cinema 4D Python scripting and plugin development.

- [Implementing Plugins](../manuals/manual_implementing_plugins.md): Explains the basic concepts of implementing plugins.
- [Input Events](../manuals/manual_input_events.md): Input events are messages about input from the keyboard or from the mouse.
- [Licensing](../manuals/manual_licensing.md): Explains licensing for Python plugins in Cinema 4D.
- [Matrices](../manuals/manual_matrices.md): Explains how to carry out transform operations.
- [Message System](../manuals/manual_message_system.md): Explains messages between Cinema 4D scene elements and interfaces.
- [Python Environment](../manuals/manual_python_environment.md): Explains the features and limitations of Cinema 4D’s Python runtime.
- [Quickstart](../manuals/manual_quickstart.md): Learn the basics of using the Cinema 4D Python API.
- [Dialog and Description Resources](../manuals/manual_resource_files.md): Explains how to define dialogs and node parameters with resource files, and how to use them from Python.
- [Scene Execution](../manuals/manual_scene_execution.md): Explains how Cinema 4D updates a scene, and where Python code runs in that process.
- [Scene Structure](../manuals/manual_scene_structure.md): Explains how a Cinema 4D scene is organized with hierarchies and branches, and how to traverse it.
- [Script Manager and Console](../manuals/manual_script_manager.md): Write and run scripts in the Script Manager and inspect results in the Python Console.
- [Scripting Elements](../manuals/manual_scripting_elements.md): Explains Python scripting elements embedded in Cinema 4D scenes.
- [Standalone Interpreter](../manuals/manual_standalone_interpreter.md): Explains how to use Cinema 4D’s standalone interpreter, c4dpy.
- [Style Guide](../manuals/manual_style_guide.md): Explains the code style and conventions used in this SDK.
- [Symbol Parsing](../manuals/manual_symbol_parsing.md): Explains resource symbols and mxutils.ImportSymbols.
- [Vectors](../manuals/manual_vectors.md): Explains how to carry out vector operations.
- [Working with the SDK](../manuals/manual_working_with_sdk.md): Set up Visual Studio Code to work with the Cinema 4D Python SDK.
