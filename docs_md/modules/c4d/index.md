## Overview <a id="overview"></a>

**Application Control**

- [`c4d.CheckIsRunning()`](#c4d.CheckIsRunning): Check if a task is running.
- [`c4d.PrefsLib_OpenDialog()`](#c4d.PrefsLib_OpenDialog): Used to open the preference dialog of Cinema 4D on a specific **page**.
- [`c4d.RestartMe()`](#c4d.RestartMe): Restarts Cinema 4D.

**Clipboard**

- [`c4d.CopyBitmapToClipboard()`](#c4d.CopyBitmapToClipboard): Copy a bitmap to the clipboard.
- [`c4d.CopyStringToClipboard()`](#c4d.CopyStringToClipboard): Copy a text to the clipboard.
- [`c4d.GetBitmapFromClipboard()`](#c4d.GetBitmapFromClipboard): Returns a bitmap from the clipboard.
- [`c4d.GetC4DClipboardOwner()`](#c4d.GetC4DClipboardOwner): Get the owner ID of the clipboard.
- [`c4d.GetClipboardType()`](#c4d.GetClipboardType): Get the type of the clipboard.
- [`c4d.GetStringFromClipboard()`](#c4d.GetStringFromClipboard): Returns a string from the clipboard.

**Commands**

- [`c4d.CallCommand()`](#c4d.CallCommand): Executes a command.
- [`c4d.GetCommandHelp()`](#c4d.GetCommandHelp): Gets the help string of a command.
- [`c4d.GetCommandName()`](#c4d.GetCommandName): Gets the name of a command.
- [`c4d.IsCommandChecked()`](#c4d.IsCommandChecked): Checks if a command is checked.
- [`c4d.IsCommandEnabled()`](#c4d.IsCommandEnabled): Checks if a command is enabled.

**Common**

- [`c4d.ClearPythonConsole()`](#c4d.ClearPythonConsole): Clears the Python console.
- [`c4d.GeGetByteOrder()`](#c4d.GeGetByteOrder): Get the type of OS that is running Cinema 4D.
- [`c4d.GeGetCurrentOS()`](#c4d.GeGetCurrentOS): Get the type of OS that is running Cinema 4D.
- [`c4d.GeGetGray()`](#c4d.GeGetGray): Get the color values for the default Cinema 4D gray.
- [`c4d.GeGetMilliSeconds()`](#c4d.GeGetMilliSeconds): Get the current timer count in milliseconds.
- [`c4d.GeGetTimer()`](#c4d.GeGetTimer): Get the current timer count in milliseconds.
- [`c4d.GetAPIVersion()`](#c4d.GetAPIVersion): Get the API version of the Python SDK, for instance **(1, 0, 1001)**
- [`c4d.GetC4DVersion()`](#c4d.GetC4DVersion): Get the version of Cinema 4D that is running, for instance **12016**.
- [`c4d.GetDefaultFPS()`](#c4d.GetDefaultFPS): Get the default frames per second value.
- [`c4d.StopAllThreads()`](#c4d.StopAllThreads): Stop all running threads.

**Data And Memory Utilities**

- [`c4d.AllocListHead()`](#c4d.AllocListHead): Allocates a list head.
- [`c4d.Cast()`](#c4d.Cast): Casts *obj* to the given *type*.
- [`c4d.CopyData()`](#c4d.CopyData): Copies a parameter data to another.
- [`c4d.GetCustomDataTypeDefault()`](#c4d.GetCustomDataTypeDefault): Retrieve the default settings for a data type.

**Deprecated**

- [`c4d.GePrint()`](#c4d.GePrint): Outputs a string to the Cinema 4D console window.
- [`c4d.GetGlobalTexturePath()`](#c4d.GetGlobalTexturePath): Use `GetGlobalTexturePaths()` instead.
- [`c4d.SetGlobalTexturePath()`](#c4d.SetGlobalTexturePath): Use `SetGlobalTexturePaths()` instead.

**Editor Operations**

- [`c4d.GetActiveNodeSpaceId()`](#c4d.GetActiveNodeSpaceId): Returns the active node space.
- [`c4d.IsAnimationRunning()`](#c4d.IsAnimationRunning): Checks if an animation is currently running.
- [`c4d.IsUVToolMode()`](#c4d.IsUVToolMode): Check if the current context is UV, if UV mode is selected or the UV Texture Editor is the last one used.
- [`c4d.StartEditorRender()`](#c4d.StartEditorRender): Starts the editor renderer.

**Interface And Scripting**

- [`c4d.CallButton()`](#c4d.CallButton): Simulates a click of a button.
- [`c4d.CallFunction()`](#c4d.CallFunction): Calls a function defined within a scripting expression.
- [`c4d.WriteConsole()`](#c4d.WriteConsole): Writes *str* to the Python console.

#### `c4d.CallFunction(op, function, arg1, arg2, arg3)` <a id="c4d.CallFunction"></a>

Calls a function defined within a scripting expression.  
This works for all parts of Cinema 4D where Python is embedded. See [Running Code in Cinema 4D](../../manuals/manual_quickstart.md#c4d-python-in-c4d-embedded).

*New in version R16.021.*

> **Note:**
>
> The arguments and returned value have to be of any Cinema 4D data type i.e. anytype or *GeData* in the C++ API.  
> Anything else will be converted to a *void** before being sent to the other object.  
> As the maximum number of arguments is *3*, to send more make one of the arguments a [`BaseContainer`](BaseContainer/index.md#c4d.BaseContainer) which can store more information.

> **Warning:**

> This risk is the same as with directly calling a function from within your own script.

**Parameters:**

- **op** ([*BaseList2D*](C4DAtom/GeListNode/BaseList2D/index.md#c4d.BaseList2D)) – The object to search the function within its script.
- **function** (*str*) – The name of the function to call.
- **arg1** (*any*) – The first optional argument.
- **arg2** (*any*) – The second optional argument.
- **arg3** (*any*) – The third optional argument.

**Return type:** Any

**Returns:** The value returned by the called function.

#### `c4d.EventAdd(flags=0)` <a id="c4d.EventAdd"></a>

Enqueues an update event for the active document, resulting in a core message being emitted.

The typical example of using [`c4d.EventAdd()`](#c4d.EventAdd) is after adding or removing elements from the active document; and wanting these changes to be reflected in the UI. The function itself is technically thread-safe, but the vast majority of operations that require calling this function are not thread-safe and must be called from the main thread (and therefore calling this function is usually main thread bound). The function also does not enqueue a dedicated event item, but rather sets a flag that is checked when the next update event is processed. Therefore, calling this function multiple times in one execution scope is unnecessary overhead which must be avoided. Because such multiple event flags cannot be consumed while a function on the main thread is still running, and instead the event will only be consumed after that function returns.

> **Warning:** Only must be called when modifying the active document and is without meaning for other documents.

**Parameters:**

**flags** (*int*) –

One of the following flags:

|   |   |
|---|---|
| *EVENT_NONE* | None. |
| *EVENT_FORCEREDRAW* | Force a complete redraw. |
| *EVENT_ANIMATE* | Animate document. |
| *EVENT_NOEXPRESSION* | Do not execute expressions. |
| *EVENT_GLHACK* | Private. |
| *EVENT_CAMERAEXPRESSION* | If set(and not *EVENT_NOEXPRESSION*) the event will only update camera dependent expressions (for faster speed). |
| *EVENT_ENQUEUE_REDRAW* | *New in version R17.032:* \| Do not stop the current redraw if [`DrawViews()`](#c4d.DrawViews) is running at the moment. \| In that case enqueue the redraw after the current draw is done. |

**Example:**

```python
import c4d
import mxutils

def AddCubes() -> None:
    '''Add 10 cubes to the active document and update the scene. Must be called from the main thread.
    '''
    if not c4d.threading.IsMainThread():
        raise RuntimeError("AddCubes must be called from the main thread.")
    
    # We could technically also call EventAdd here with the same effect, as the event will only happen after 
    # this function returns.
    # c4d.EventAdd()

    doc: c4d.documents.BaseDocument = c4d.documents.GetActiveDocument()
    for i in range(10):
        cube: c4d.BaseObject = mxutils.CheckType(c4d.BaseObject(c4d.Ocube))
        doc.InsertObject(cube)

        # Calling EventAdd here would have no extra effect, since this event cannot be consumed while our 
        # main thread function is still running. And such extra calls on a large scale can cause 
        # considerable overhead. Python is too slow that this can ever be a real problem unlike in C++,
        # but you should still avoid multiple calls to EventAdd within one execution context.
        # c4d.EventAdd()

    # The very end of a function or scope is the canonical place to call EventAdd(). With this call,
    # we notify Cinema 4D that we changed scene data and that the UI must be updated. The scene data
    # has changed as soon as we made our edits and is not waiting for this event to be processed.
    c4d.EventAdd()
```

#### `c4d.SpecialEventAdd(messageid, p1=0, p2=0)` <a id="c4d.SpecialEventAdd"></a>
