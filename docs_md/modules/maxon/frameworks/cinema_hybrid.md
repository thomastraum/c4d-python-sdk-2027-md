# maxon.frameworks.cinema_hybrid <a id="maxon-frameworks-cinema-hybrid"></a><a id="framework-cinema-hybrid"></a>

> **Note:** Members documented here are defined in `maxon.frameworks.cinema_hybrid` module and are also exposed to the global `maxon` module. See the [Maxon API](../../../manuals/manual_api_overview.md#maxon-api-introduction) section of the API Overview for more information about the special conventions of this API.

## Description <a id="description"></a>

Module for interoperability between the Cinema and Maxon APIs.  
Many elements in this framework are tied directly or indirectly to GUI operations.

> **Warning:** This framework will be progressively reduced in future versions of Cinema 4D and, at the end, completely dismissed.
