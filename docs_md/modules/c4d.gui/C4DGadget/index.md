## *class* `c4d.gui.C4DGadget` <a id="c4d.gui.C4DGadget"></a>

This class has no methods but is needed for [`GeDialog`](../GeDialog/index.md#c4d.gui.GeDialog)’s [get](../GeDialog/index.md#get-methods) and [set](../GeDialog/index.md#set-methods) methods.
