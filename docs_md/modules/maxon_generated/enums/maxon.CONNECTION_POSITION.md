# maxon.CONNECTION_POSITION <a id="maxon-connection-position"></a>

## Description <a id="module-maxon.CONNECTION_POSITION"></a><a id="description"></a>

Graph connections can “store attribute values” `GraphNode.GetConnectionValue()` at three different positions:

- At their source
- At their center
- At their target
