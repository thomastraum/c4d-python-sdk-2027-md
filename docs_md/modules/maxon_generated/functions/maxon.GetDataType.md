# maxon.GetDataType <a id="maxon-getdatatype"></a>

## `maxon.GetDataType(obj)` <a id="maxon.GetDataType"></a>

Retrieves the [`maxon.DataType`](../datatypes/base_core/maxon.DataType.md#module-maxon.DataType) of the passed object.

**Parameters:** **type** – The object to retrieves the [`maxon.DataType`](../datatypes/base_core/maxon.DataType.md#module-maxon.DataType) from.

**Type:** [`maxon.Data`](../datatypes/base_core/maxon.Data.md#module-maxon.Data)

**Returns:** The datatype.

**Return type:** [`maxon.DataType`](../datatypes/base_core/maxon.DataType.md#module-maxon.DataType)
