# maxon.InOutputStreamInterface <a id="maxon-inoutputstreaminterface"></a>

## Description <a id="module-maxon.InOutputStreamInterface"></a><a id="description"></a>

Creates an [`maxon.InOutputStreamInterface`](#module-maxon.InOutputStreamInterface) class to read/write bytes from/into streams.
