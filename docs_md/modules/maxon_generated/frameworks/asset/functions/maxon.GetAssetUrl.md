# maxon.GetAssetUrl <a id="maxon-getasseturl"></a>

## `maxon.GetAssetUrl(asset)` <a id="maxon.GetAssetUrl"></a>

Returns the url of a DndAsset.

**Parameters:** **asset** (Tuple( [`maxon.AssetDescription`](../reference/maxon.AssetDescription.md#module-maxon.AssetDescription), [`maxon.Url`](../../../references/io/maxon.Url.md#module-maxon.Url), [`maxon.String`](../../../references/core/maxon.String.md#module-maxon.String))) – Drag&Drop asset to check.

**Returns:** Url on success.

**Return type:** [`maxon.Url`](../../../references/io/maxon.Url.md#module-maxon.Url)
