# maxon.IdToIdAndVersion <a id="maxon-idtoidandversion"></a>

## `maxon.IdToIdAndVersion(id)` <a id="maxon.IdToIdAndVersion"></a>

Convert a compacted id back to an id and version.

**Parameters:** **id** ([`maxon.Id`](../../../datatypes/id/maxon.Id.md#module-maxon.Id)) – Compacted id.

**Returns:** Extracted Id and version on success.

**Return type:** [`maxon.Tuple`](../../../datatypes/collection/maxon.Tuple.md#module-maxon.Tuple) [[`maxon.Id`](../../../datatypes/id/maxon.Id.md#module-maxon.Id), [`maxon.Id`](../../../datatypes/id/maxon.Id.md#module-maxon.Id)]
