# maxon.Reverse <a id="maxon-reverse"></a>

## `maxon.Reverse(pDir)` <a id="maxon.Reverse"></a>

Returns the reverse of the given direction. PORT_DIR.INPUT becomes PORT_DIR.OUTPUT and vice versa.

**Parameters:** **pDir** ([`maxon.PORT_DIR`](../../../enums/maxon.PORT_DIR.md#module-maxon.PORT_DIR)) – A direction.

**Returns:** [`maxon.PORT_DIR`](../../../enums/maxon.PORT_DIR.md#module-maxon.PORT_DIR)

**Return type:** The reverse of *dir*.
