# Manuals <a id="manuals"></a>

Browse guides for Cinema 4D Python scripting and plugin development.

## Getting Started <a id="getting-started"></a>

- [Quickstart](manual_quickstart.md): Learn the basics of using the Cinema 4D Python API.
- [Working with the SDK](manual_working_with_sdk.md): Set up Visual Studio Code to work with the Cinema 4D Python SDK.
- [Script Manager and Console](manual_script_manager.md): Write and run scripts in the Script Manager and inspect results in the Python Console.
- [Standalone Interpreter](manual_standalone_interpreter.md): Explains how to use Cinema 4D’s standalone interpreter, c4dpy.
- [Python Environment](manual_python_environment.md): Explains the features and limitations of Cinema 4D’s Python runtime.
- [Style Guide](manual_style_guide.md): Explains the code style and conventions used in this SDK.

## Plugins <a id="plugins"></a>

- [Implementing Plugins](manual_implementing_plugins.md): Explains the basic concepts of implementing plugins.
- [Scripting Elements](manual_scripting_elements.md): Explains Python scripting elements embedded in Cinema 4D scenes.
- [Debugging](manual_debugging.md): Explains how to find errors in Python code for Cinema 4D with the mxutils debug tools, and how to track down crashes caused by threading violations.
- [External Libraries](manual_external_libraries.md): Explains how to expose third-party libraries to Cinema 4D Python.
- [Dialog and Description Resources](manual_resource_files.md): Explains how to define dialogs and node parameters with resource files, and how to use them from Python.
- [Symbol Parsing](manual_symbol_parsing.md): Explains resource symbols and mxutils.ImportSymbols.
- [Licensing](manual_licensing.md): Explains licensing for Python plugins in Cinema 4D.

## API <a id="api"></a>

- [API Overview](manual_api_overview.md): Provides an overview of the major API components.
- [Vectors](manual_vectors.md): Explains how to carry out vector operations.
- [Matrices](manual_matrices.md): Explains how to carry out transform operations.
- [Scene Structure](manual_scene_structure.md): Explains how a Cinema 4D scene is organized with hierarchies and branches, and how to traverse it.
- [Scene Execution](manual_scene_execution.md): Explains how Cinema 4D updates a scene, and where Python code runs in that process.
- [Geometry Model](manual_geometry.md): Explains the geometry model of Cinema 4D: polygons, edges, normals, caches, and splines.
- [Message System](manual_message_system.md): Explains messages between Cinema 4D scene elements and interfaces.
- [Input Events](manual_input_events.md): Input events are messages about input from the keyboard or from the mouse.
- [Assets](manual_assets.md): Provide content as reusable assets served with the Cinema 4D Asset Browser.
- [Graph Descriptions](manual_graph_descriptions.md): Explains how to generate node materials with graph descriptions.
